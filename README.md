# Ask About Card

An Anki add-on: while you review a card, ask a question about it and get an answer in a small window next to
your card, with formulas rendered the same way as on your cards. You can ask follow-up questions.

The answers come from the [Codex CLI](https://github.com/openai/codex), OpenAI's command-line program, which
must be **installed and signed in on your computer**. The add-on only starts that program. It contains no
account, key or password, and it never reads, stores or forwards your sign-in.

## What it does

1. While reviewing a card, press **Ctrl+Shift+F** (**⌘⇧F** on a Mac), or right-click the card → *Ask About Card …*,
   or use the menu *Tools → Ask About Card …*.
2. If you highlighted some text on the card first, the question is about that part. Otherwise it is about the
   whole card (front and back).
3. Type your question and choose a mode:
   - **Explain**: a clear explanation.
   - **Give only a hint**: one short hint, no full solution.
   - **Check my reasoning**: you describe your own thinking and get told what is right, missing or wrong.
4. Press **Ctrl+Enter** (**⌘↩** on a Mac) or click *Ask*. The answer usually arrives after 10 to 30 seconds.
   *Cancel* stops a running request; your question stays in the box.

Each conversation is saved as a readable Markdown file in `~/Documents/Anki Questions` (you can change the folder
or switch saving off). Follow-up questions go into the same file.

**Explain on highlight (optional, off by default):** switch it on in the menu *Tools → Ask About Card: explain
on highlight*. After that, highlighting text on a card with the mouse is enough: the window opens and explains
that part by itself. Note that every highlight then sends a request.

## What it does not do

- It never changes a card, a note or a deck.
- Codex receives only the text of the current card, your question and the earlier questions and answers of the
  same window. It is started without tools: it cannot read your files, change anything or use the internet.
- The text of the card is treated as content to be discussed, not as instructions.
- It opens nothing and starts nothing when Anki starts. Its own errors go to a log file
  (`user_files/errors.log` in the add-on's folder), never into a pop-up.
- It does not exist for AnkiMobile or AnkiDroid; phone apps do not support add-ons.

## Your account, privacy and the provider's rules

- When you ask a question, the text of the card and your question are sent to OpenAI by the Codex CLI, under
  **your own account**. Nothing is sent anywhere else, and nothing is sent unless you ask a question (or
  highlight text while *explain on highlight* is on).
- Your use of Codex is covered by the agreement between you and OpenAI (its terms of use and usage policies),
  and requests count against your own plan or API key. Please read those terms; this add-on does not change them.
- The add-on is free and non-commercial. It is an independent project: **not affiliated with, endorsed by or
  supported by OpenAI or Anki**. "OpenAI" and "Codex" are named only to say which program is needed.
- Answers are generated by an AI model and can be wrong. Check anything important against your course material.

## What you need

- Anki on a computer. Developed and tested with **Anki 25.09 on macOS**. It is written to also run on Linux and
  Windows, but that has not been tested yet; reports are welcome.
- The Codex CLI, installed and signed in. Check in a terminal: `codex login status`

## Install

1. Download `ask_about_card.ankiaddon` from the **Releases** page of this repository.
2. In Anki: *Tools → Add-ons → Install from file…*, choose the downloaded file.
3. Restart Anki.

## First try

1. Review a deck and show the answer of a card.
2. Highlight a word or a formula on the card and press **Ctrl+Shift+F** (**⌘⇧F**).
3. Type "Why is this true?" and press **Ctrl+Enter** (**⌘↩**).

If the window says Codex was not found: open a terminal, run `which codex`, and paste the path it prints into
`codex_path` in the add-on's Config.

## Settings

*Tools → Add-ons → Ask About Card → Config*. Every field is explained next to the settings.

| Setting | Meaning | Default |
|---|---|---|
| `codex_path` | full path to the Codex CLI; empty = search for it | empty |
| `model` | model name; empty = the program's default | empty |
| `timeout_seconds` | 10 to 1800 | 180 |
| `shortcut` | shortcut while reviewing; empty = none | `Ctrl+Shift+F` |
| `explain_on_highlight` | explain highlighted text automatically | `false` |
| `highlight_min_chars` | shortest highlight that counts | 3 |
| `save_folder` | where conversations are saved; empty = do not save | `~/Documents/Anki Questions` |
| `answer_language` | for example `"German"`; empty = the language of your question | empty |

## Remove

In Anki: *Tools → Add-ons*, select *Ask About Card*, *Delete*. Your saved conversations stay where they are.

## For developers

| File | Content |
|---|---|
| `addon/core.py` | everything that works without Anki: card text, the request, starting the program with cancel and time limit, answer as HTML, saving |
| `addon/window.py` | question window, menu, right click, shortcut |
| `addon/__init__.py` | only registers the entry points when Anki starts |
| `addon/config.json`, `addon/config.md` | default settings and their explanation |
| `build.py` | packs `addon/` into `dist/ask_about_card.ankiaddon` |

Tests:

```
python3 -B tests/test_core.py
"$HOME/Library/Application Support/AnkiProgramFiles/.venv/bin/python" -B tests/test_window.py
```

The tests work in throw-away folders with a stand-in program instead of the Codex CLI. `test_window.py` uses
Anki's real Python modules (the path above is where Anki keeps its Python on a Mac), but invisibly and without
starting Anki. With any other Python those tests are skipped.

Build the installable file:

```
python3 build.py
```
